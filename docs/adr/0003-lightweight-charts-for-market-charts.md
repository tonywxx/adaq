# Use Lightweight Charts for market charts

ADAQ uses TradingView Lightweight Charts v5 for interactive OHLCV and volume charts instead of the already-installed general-purpose Recharts library. Authoritative decimal strings and Unix-millisecond times remain unchanged outside `MarketChartAdapter`, which alone converts them to JavaScript numbers and second-based chart timestamps and represents Bar Gaps as `WhitespaceData`; crosshair and detail values always come from the original decimal strings rather than values read back from the chart. The volume histogram uses Base Volume, while crosshair details show both Base Volume and Quote Volume. Charts load older history on demand as the viewport approaches its left edge instead of fetching the maximum range initially, and the TradingView attribution logo remains enabled to satisfy the required user-visible link.
