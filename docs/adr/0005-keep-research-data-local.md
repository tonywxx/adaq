# Keep research data local and cloud data control-only

ADAQ is local-first: Parquet is the authoritative device-shared historical market-data store, DuckDB is an optional rebuildable query and analytics layer over that data, and SQLite stores user configuration, operational metadata, Run records, Component Library access, and the local journal. Component Package bytes may be content-addressed and deduplicated on one device, but visibility and execution rights remain User-scoped; M3 manual imports belong only to the importing User, while future purchases are governed by cloud Component Entitlements and registered-device rules. Supabase stores registration identity and may hold control-plane information such as entitlements, licences, and registered devices, but it does not own authoritative research data or exchange credentials. A future Axum service may distribute versioned datasets, packages, licences, and sync data without becoming the live Venue execution path.
