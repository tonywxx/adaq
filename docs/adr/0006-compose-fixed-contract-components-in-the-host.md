# Compose fixed-contract Components in the host

ADAQ loads Factor and Strategy Components in-process with Wasmtime and accepts only exact versioned ADAQ contracts; embedded Component Type and WIT describe the binary ABI, while the package manifest is authoritative for identity, independent component, SDK, and ABI versions, parameters, dependencies, supported contexts, hashes, and trust. Components cannot load or call one another, submit orders, or receive ambient network, filesystem, environment, process, real-clock, or random capabilities: the host resolves Built-in and External dependencies before a Run, keeps Embedded logic inside its Strategy Component, freezes exact packages in a Component Lock, and supplies dense fixed-order analytical values under resource limits. V1 provides a Rust SDK and CLI with conformance checks for the exact ABI, forbidden imports, determinism, chunk-boundary independence, schema alignment, target ranges, and package integrity; its free classic Indicator engine uses a pinned official C TA-Lib build behind the host contract so it can later be replaced without recompiling Strategy Components.
