# Compose fixed-contract Components in the host

ADAQ loads Factor and Strategy Components in-process with Wasmtime and accepts only exact versioned ADAQ contracts; embedded Component Type and WIT describe the binary ABI, while the package manifest is authoritative for identity, independent component, SDK, and ABI versions, parameters, dependencies, and hashes. Market suitability remains evidence in Recommended Contexts and Validation Reports rather than a vague manifest capability. Signatures, trust records, and Validation Reports remain external records keyed by the immutable package hash. Components cannot load or call one another, submit orders, or receive ambient network, filesystem, environment, process, real-clock, or random capabilities: the host resolves Built-in and External dependencies before a Run, keeps Embedded logic inside its Strategy Component, freezes exact packages in a Component Lock, and supplies dense fixed-order analytical values under resource limits. V1 provides one Tauri-independent guest SDK crate plus one host-side tooling crate that exposes shared package and conformance APIs together with the `adaq-component` CLI; Tauri imports the library and never invokes the CLI. Conformance covers the exact ABI, forbidden imports, determinism, chunk-boundary independence, schema alignment, target ranges, and package integrity. The free classic Indicator engine uses a pinned official C TA-Lib build behind the host contract so it can later be replaced without recompiling Strategy Components.
