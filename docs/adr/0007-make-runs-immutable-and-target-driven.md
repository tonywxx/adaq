# Make Runs immutable and target-driven

V1 invokes a Strategy Instance only on confirmed Closed Bars after host-owned warmup and pauses instead of supplying zero, NaN, or incomplete inputs when required data is missing. A Backtest Run immutably binds its Market Data Snapshot, Component Lock, parameters, Indicator Plan, Execution Profile, initial Strategy Allocation, engine version, and seed; a fingerprint makes identical submissions idempotent, while any changed binding creates a new Run. M3 is Spot and Long Only: Target Exposure is a `[0,1]` decimal fraction of current Strategy Equity, Taker orders fill no earlier than the next Bar open, and Maker orders use deterministic post-only limits starting with the next Bar. The host persists Target Decisions, Simulated Order lifecycles, Fills, per-Bar Equity, fees, and metrics; it retains open positions at the end and uses exact instrument precision, maker/taker fees, slippage, and rebalance rules from the frozen Execution Profile.
