# Make Runs immutable and target-driven

V1 invokes a Strategy Instance only on confirmed Closed Bars for one Instrument and one Bar Interval after host-owned warmup, and pauses instead of supplying zero, NaN, or incomplete inputs when required data is missing. A Backtest Run immutably binds its Market Data Snapshot, Component Lock, parameters, Indicator Plan, Execution Profile, allocation, position mode, engine version, and seed; changing any binding creates a new Run, and replaying identical inputs must reproduce the same persisted Target Decisions. Every invocation returns a complete decimal-string Target Exposure—long-only `[0,1]` or long-short `[-1,1]`—and the host derives simulated orders from the difference to actual exposure, with execution no earlier than the next eligible market event and under the frozen fee, slippage, precision, minimum-notional, and rebalance rules.
