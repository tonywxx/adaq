# Package Components as .adaq archives

ADAQ packages each local Component as one immutable `.adaq` ZIP containing only `manifest.json` and `component.wasm`. The manifest uses an immutable UUID Component identity plus SemVer, records the exact SDK version used to build it, and declares the exact Component kind, ABI, parameters, inputs, outputs, dependencies, warmup, and WASM SHA-256; importing a different hash for the same identity and version fails. SDK version is reproducibility metadata, while host compatibility requires an exact ABI match plus passing conformance. Signatures, trust records, and Validation Reports remain outside the archive and reference its package hash. A device may deduplicate identical package bytes, but Component Library visibility and execution remain User-scoped, and every Run freezes exact versions and hashes in its Component Lock.
