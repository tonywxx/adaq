# Reset analytical state at Bar Gaps

Every explicit Bar Gap ends one Continuous Bar Segment and causes ADAQ to recreate all Indicator, Factor, and Strategy state before the next segment, then repeat the Frozen Indicator Plan's exact Warmup. Warmup is the host-enforced minimum suppression period: an External Factor may legally return a value during Warmup and the host ignores it, while `none` after Warmup creates `Run Pause::MissingInput` under the unchanged `adaq:factor@1.0.0` option contract. A present Factor row must match its declared output names in exact count and order and contain only finite values. Host-owned capital, positions, and execution state remain unchanged, and no synthetic Bar, Feature Frame, Target Decision, or order intention is produced for missing inputs. Expected Warmup or missing required Slot values create an auditable Run Pause; a malformed present row, non-finite value, decimal conversion overflow, or TA-Lib error instead fails the Run with its Bar, Slot, source, and cause. This conservative boundary prevents hidden analytical continuity across missing market data and prevents invalid numerical results from being mistaken for ordinary absence.
