# Freeze an explicit Indicator Catalog

`adaq-indicator-catalog@1.0.0` explicitly exposes 160 of the 161 functions defined by the pinned TA-Lib v0.7.1 `ta_func_api.xml`, representing 179 bindable outputs after multi-output functions are expanded. The only excluded function is `MAVP`, whose required per-Bar dynamic period series does not fit M5's OHLCV-input and fixed-parameter Plan model. Every included definition is frozen with its inputs, parameters, outputs, lookback behavior, the official `Unstable Period` flag, and golden vectors; TA-Lib upgrades or newly discovered functions never change the ADAQ Catalog automatically. TA-Lib v0.7.1 does not provide a machine-readable numerical-stability classification, so ADAQ does not invent one. Warmup marks first output availability, not convergence, and the `Unstable Period` flag plus any upstream-documented stability notes are explanatory rather than permission for the host to add hidden history or change TA-Lib's default unstable periods. Stability notes are non-identity documentation metadata: they do not enter the Indicator Plan or affect `planHash`. Stable Indicator IDs are the lowercase TA abbreviation with underscores changed to hyphens, parameter IDs are normalized lower-kebab-case names, every single-output Indicator uses output ID `value`, and multi-output Indicators use frozen semantic IDs such as `upper-band`, `signal`, or `histogram`. Fixed TA price roles map only to the matching OHLCV fields; generic real inputs explicitly select an OHLCV field, and every TA volume role explicitly selects `base-volume` or `quote-volume` with no default. Plans freeze these mappings and cannot feed Indicators from other Indicators, Slots, Instruments, time values, or arbitrary arrays in M5. Raw C symbols remain traceability metadata, while display labels and descriptions are non-identity metadata that may be localized; published IDs are never renamed for presentation. `MAVP` may be added only after ADAQ defines a versioned dynamic-series input contract.
