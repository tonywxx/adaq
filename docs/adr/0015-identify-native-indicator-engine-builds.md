# Identify native Indicator Engine builds

ADAQ treats deterministic replay as a property of one exact native Indicator Engine build rather than assuming different C compilers and platform math libraries are bit-identical. Repeated evaluation by the same build must produce identical `f64` bits, while macOS ARM64, Windows x86_64, and Linux x86_64 golden tests require identical Warmup, alignment, counts, integer, index, and candlestick outputs and accept real outputs only when absolute or relative error is at most `1e-12`; non-finite values always fail. Indicator Engine identity includes the TA-Lib source SHA-256, Catalog version, ADAQ wrapper version, target triple, and a hash of the C compiler identity and build flags. The identity participates in the Indicator Plan hash, so exact replay requires the same build while cross-platform builds promise numerical equivalence rather than shared Run identity.
