# Require Catalog-wide multi-platform acceptance

M5 is complete only when the vendored TA-Lib archive checksum and official C regression suite pass and the library builds statically on macOS ARM64, Windows x86_64, and Linux x86_64 CI. Catalog checks must prove exactly 160 Indicators and 179 outputs with no `mavp`, unique canonical metadata, successful compilation and lookback calculation, and committed reference golden vectors for every output that are not generated by the Engine under test. Plan tests cover Market, Built-in, External, multi-output and repeated-Factor aliases; defaults, literals, Strategy parameter references and canonical hashes; and rejection of unknowns, type or range errors, incomplete or extra Slots, order mismatches, wrong Engine identities and resource violations. Run Engine tests cover Market-only, Built-in-only, Factor-only and mixed order, Warmup, post-Warmup Factor absence, non-finite failures, Bar Gap resets, Strategy recreation, chunk independence, and rejection of Factors with more than 64 outputs or rows that differ from their exact declared names and order. SDK and tooling acceptance migrates templates to `manifestSchemaVersion` and `featureSlots`, rejects `inputNames`, validates dependency and parameter bindings, and includes Market, Built-in and External developer examples. After those APIs and examples are implemented and verified, the agent authors complete Strategy and Factor developer guides, executable examples, build/verify/package instructions, and troubleshooting material; generated Catalog and Manifest references plus JSON Schema come from their machine-readable sources and CI rejects drift. The user reviews these deliverables but is not expected to author them. M5 stops at in-memory Plan, Indicator Engine, and Run Engine integration; Run persistence, full simulation, UI, marketplace, and live trading remain outside the milestone.
