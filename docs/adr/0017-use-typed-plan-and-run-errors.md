# Use typed Plan and Run errors

M5 replaces string-only host failures with Tauri-independent typed errors. Indicator Plan validation returns a deterministically ordered collection of issues carrying a stable lower-kebab-case code and optional Slot, source, and field context, while Run execution fails fast with one error carrying code, stage, optional Bar, Slot and source, and a bounded cause; Run Pause remains a normal domain result rather than an error. TA-Lib failures preserve the normalized code plus original numeric and symbolic return code, Component-provided causes are capped at 4 KiB and marked when truncated, and tests match codes rather than English messages. Panics, FFI pointers, and internal host details never cross the boundary, and a future UI maps these engine types to IPC DTOs instead of defining the engine around presentation concerns.
