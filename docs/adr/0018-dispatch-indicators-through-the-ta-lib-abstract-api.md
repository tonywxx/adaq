# Dispatch Indicators through the TA-Lib Abstract API

ADAQ implements the 160-function Catalog through one audited private wrapper over the official `ta_abstract.h` API rather than generating per-Indicator Rust modules. Compile resolves only raw TA function names already present in the explicit Catalog and validates parameter holders, outputs, and lookbacks; evaluation owns and releases its holders and buffers without exposing C handles or pointers beyond `adaq-indicator-engine`. Catalog source is generated from the vendored `ta_func_api.xml`, committed for review, and regenerated in CI with a no-diff check, while Rust FFI bindings are generated from the pinned headers and committed so normal Cargo builds require neither bindgen nor libclang. Source, XML, and header checksums are verified together, runtime enumeration never expands the public Catalog, and exceptional output naming is metadata-driven rather than implemented with 160 handwritten branches.
