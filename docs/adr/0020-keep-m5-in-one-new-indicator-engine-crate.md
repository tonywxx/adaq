# Keep M5 in one new Indicator Engine crate

M5 adds only `adaq-indicator-engine`, which owns the vendored TA-Lib source and static build, generated bindings and Catalog, FFI, compile/evaluate API, Engine identity, and typed Engine errors. Existing `adaq-component-tooling` depends on it and owns Manifest 1.0, Feature source and Frozen Indicator Plan types, validation, JCS hashing, templates, conformance, and CLI verification; the guest `adaq-component-sdk` remains free of TA-Lib, Catalog, and Plan dependencies and gains only source-agnostic Slot index helpers. The application `run_engine.rs` continues to orchestrate Market, Built-in, Factor, and Strategy execution, while `ada-backtest-core` does not absorb M6 persistence or full-simulation work early. M5 introduces no separate Catalog or Run Engine crate, trait, factory, or plugin abstraction; the CLI's additional native build cost is accepted until a real lightweight Catalog consumer justifies another crate boundary.
