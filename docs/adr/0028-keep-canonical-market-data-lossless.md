# Keep Canonical Market Data lossless

AdaQ V1 permits only lossless canonicalization of Source Market Data: provider identity mapping, UTC and Bar Interval validation, exact Decimal representation, deterministic ordering, and collapse of identical duplicates. Missing fields, invalid financial invariants, misaligned times, or conflicting identities and values produce retained Quarantined Market Records and explicit gaps; statistically unusual but structurally valid observations receive warnings rather than automatic deletion. REST refetches create new Source and Canonical revisions instead of mutating published evidence. Canonicalization never forward-fills, interpolates, clips, winsorizes, normalizes, or accepts manual value edits; those research transformations must create separately identified derived Feature evidence. A Data Quality Report publishes Passed, Degraded, or Rejected state so usable incomplete evidence is distinguishable from a Dataset that cannot be trusted or published.
