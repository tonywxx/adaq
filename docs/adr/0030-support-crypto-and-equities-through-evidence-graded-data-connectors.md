# Support crypto and equities through evidence-graded data connectors

ADR 0030 supersedes the crypto-only scope in ADR 0001 and limits ADR 0026 to the OKX Spot slice. AdaQ V1 supports OKX Spot, China A-share Equity Instruments, and United States Equity Instruments without introducing a speculative unified-data service: each remains a host-owned Market Data Connector behind the existing Tauri-independent data core. The A-share Connector uses `akshare-rs` but records the actual upstream provider, method, request, response, and connector version because the library aggregates multiple unofficial sources; Canonical equity Bars must use an Unadjusted Price Basis, while corporate-action adjustments are provenance-bound derived data. The United States Connector uses Alpaca Market Data Basic as its primary source and binds every acquisition to a runtime Provider Capability Snapshot so IEX-only realtime coverage, delays, history, rate limits, and streaming-symbol limits are never presented as consolidated realtime coverage. `yfinance-rs` is an explicitly unofficial auxiliary source for fallback or cross-checking historical, corporate-action, and fundamental evidence, not the sole authority for realtime or silently repaired Canonical data. Provider limitations may degrade coverage but never weaken Source retention, Canonical validation, or user-visible provenance.
