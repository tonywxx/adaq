# Train Models in controlled workers and deploy inference-only Components

AdaQ V1 keeps the M8 Model Component contract inference-only and adds a host-owned Model Lab that orchestrates immutable Model Training Protocols through the Model-kind contract of a versioned `adaq-python-research-runner` child process. The Runner receives exact local Feature and Factor evidence, Targets, windows, Host-owned fitted transformations, algorithm, hyperparameters, Model Research Adapter version, Seed, environment identity, and resource policy; it does not execute on the Tauri UI thread or write authoritative ADAQ records directly, and a fresh process serves each Attempt. Each execution is a cancellable Model Training Attempt whose crash or failure is isolated from the desktop and whose diagnostics, logs, and partial checkpoints remain evidence without publishing an Artifact. The first registered path uses the Qlib Ridge Adapter over a Host-fed Dataset Bridge and publishes a data-only Linear Model Artifact after reloading it and reproducing its Forecasts; no Python pickle becomes authoritative. The host validates a Completed Attempt and atomically publishes its immutable Model Artifact, then generates and evaluates Forecast Signal Datasets through the existing evidence contracts. A Model Exporter may convert only explicitly supported Artifact schemas and algorithms into a candidate `model-*.adaq` inference Component, which must pass normal package validation, deterministic replay, runtime limits, and Component Equivalence before import. Frameworks, preprocessing, or models without a conforming Adapter and Exporter remain available only for controlled offline exploration or Externally Generated Signal Datasets and are never represented as deployable Components. The separately supervised `adaq-model-runner` is reserved for a future explicitly qualified Local Qlib Paper Artifact and never executes arbitrary research Projects. This preserves Python training flexibility without placing training frameworks, mutable checkpoints, ambient notebooks, or non-reproducible execution inside the WASM ABI.
