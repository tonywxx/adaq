# Train Models in controlled workers and deploy inference-only Components

AdaQ V1 keeps the M8 Model Component contract inference-only and adds a host-owned Model Lab that orchestrates immutable Model Training Protocols through a versioned `adaq-model-runner` child process. The Runner receives exact local Feature and Factor evidence, Targets, windows, fitted transformations, algorithm, hyperparameters, framework and Adapter versions, Seed, environment identity, and resource policy; it does not execute on the Tauri UI thread or write authoritative ADAQ records directly. Each execution is a cancellable Model Training Attempt whose crash or failure is isolated from the desktop and whose diagnostics, logs, and partial checkpoints remain evidence without publishing an Artifact. The host validates a Completed Attempt and atomically publishes its immutable Model Artifact, then generates and evaluates Forecast Signal Datasets through the existing evidence contracts. A Model Exporter may convert only explicitly supported Artifact schemas and algorithms into a candidate `model-*.adaq` inference Component, which must pass normal package validation, deterministic replay, runtime limits, and Component Equivalence before import. Frameworks or models without a conforming Exporter remain available for controlled offline research or Externally Generated Signal Datasets but are never represented as deployable Components. This preserves Python training flexibility without placing training frameworks, mutable checkpoints, ambient notebooks, or non-reproducible execution inside the WASM ABI.
