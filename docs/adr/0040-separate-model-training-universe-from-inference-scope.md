# Separate Model Training Universe from inference Scope

ADAQ V1 supports both Single-Instrument and Cross-Sectional Model Scopes while recording Training Universe independently. A Model trained on a panel of many Instruments remains Single Instrument when each prediction depends only on that Instrument's inputs; ranking, graph, attention, or other models whose prediction jointly depends on peers declare Cross Sectional. The Single-Instrument world retains the M8 causal batch contract. The Cross-Sectional world receives one deterministic Instrument-ID-ordered Prediction Batch for an exact Observation Time, bound to its Point-in-Time Instrument Universe, Universe Evidence State, Feature Plan, availability, and explicit missingness, and returns Instrument-keyed Forecast Signals for those identities. Current listings never substitute for historical membership, and unavailable members are not silently dropped. This expands the V1 Model ABI beyond M8 without forcing ordinary Qlib panel-trained models into a more expensive or semantically false Cross-Sectional runtime.
