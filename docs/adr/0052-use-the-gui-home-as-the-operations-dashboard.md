# Use the GUI home as the Operations Dashboard

ADAQ V1 makes the existing Tauri and React `/` route the localized Operations Dashboard for global Paper Trading and research status rather than a Crypto-only market screen, and it does not build a parallel TUI. The existing Watchlist, Ticker, and Kline experience moves intact to a separate Crypto Market route under the sidebar's market navigation. The Dashboard paints its shell immediately, reads a user-scoped Dashboard Projection, reuses current-session cached read data on re-entry, refreshes in the background, and applies incremental Tauri host events without polling every subsystem; native work and loading remain scoped to the owning card. It summarizes System Health, Critical Alerts, market sessions, Paper Accounts, active Bots, positions, native-currency PnL, Orders, Fills, Risk, reconciliation, data work, Factor research, Model training, Component builds, Backtests, and Validation, while detailed evidence stays in linked domain pages. It never adds CNY, USD, and USDT without an FX Snapshot, turns a research Attempt into a generic mutable Job, treats frontend state as authority, or calls a Worker, SQLite, or provider directly. Freeze All is persistently accessible when Bots are active, while Flatten All remains separately confirmed through host commands. English (US), Simplified Chinese, keyboard access, screen-reader labels, and failure/loading states ship together. A future headless or remote runtime may add a read-only CLI or TUI, but V1 remains one desktop GUI control plane.
