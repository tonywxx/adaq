# Seed the User Watchlist once across markets

ADAQ seeds one User-scoped Watchlist with the ordered Crypto, China A-share, and U.S. equity defaults when the Watchlist is first created, and applies a versioned additive backfill to existing accounts. The seed runs once, preserves existing items, and never refills items a User later removes, keeping the requested baseline without turning the Watchlist into permanent favorites or separate per-market lists.
