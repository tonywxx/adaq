# Replace the Factor ABI with scope-specific Feature batches

ADAQ M11 replaces pre-v1 `adaq:factor@1.0.0` with a Factor ABI v2 that declares exactly one Time-Series or Cross-Sectional Scope and consumes only host-resolved ordered Feature inputs. Time-Series execution receives dense Present rows from one Instrument in causal order while the host publishes unavailable rows and rebuilds state at missing inputs or Bar Gaps; Cross-Sectional execution receives every member of one deterministic Point-in-Time Instrument Universe with explicit available or typed-unavailable cells and must return the same identities and order. The host rejects shape, membership, order, availability, non-finite value, output, or resource violations before evidence publication; incompatible pre-v1 packages require explicit Reset rather than a dual reader or migration because preserving the Closed-Bar-only ABI would make Cross-Sectional support nominal and permit Component-owned preprocessing to diverge from Feature evidence.
