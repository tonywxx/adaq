# Separate free Community source from qualified Marketplace products

The post-V1 ADAQ Marketplace treats a Community Python Project and a qualified Component or Model Product as different product classes. Each Community Python Project version is a deterministic source ZIP containing only its validated Python Project Layout and an explicit SPDX open-source licence that permits source redistribution; it has a fixed zero price with no payment, refund, or paid Entitlement lifecycle. Local proprietary archives may use `LicenseRef-Proprietary` but cannot be Community listings, because zero price does not grant redistribution rights. Data, results, environments, caches, secrets, undeclared files, and opaque ADAQ-specific binary wrappers are excluded. Publication or installation never grants execution trust, research validity, Component eligibility, Paper Trading authority, or Real Trading Qualification. V1 supports local directory and ZIP import and export of the same source-visible project shape without hosting a Marketplace. Qualified Components and Models may later be free or paid under their own provenance, conformance, equivalence, security, licence, review, and entitlement gates, and a Community listing cannot bypass those gates.
