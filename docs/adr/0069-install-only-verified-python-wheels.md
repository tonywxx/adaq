# Install only verified Python wheels

ADAQ publishes `python/adaq-research-sdk/` as the `adaq-research-sdk` distribution with the `adaq` import namespace, bundles the exact SDK wheel used by the application, and never resolves a running Project against the latest public release. The private `python/adaq-python-research-runner/` wheel supplies only the isolated `adaq_runner` process entry and protocol client and is not part of the public SDK surface. Each supported platform receives an ADAQ-signed base wheelhouse for both wheels, the Qlib Adapter, Arrow transport, and their qualified dependencies. `pyproject.toml` expresses dependency intent, but only explicit Sync Environment may resolve project-specific additions from trusted indexes to platform-compatible wheels and atomically write their exact versions and hashes to `pylock.toml`; V1 rejects source distributions and never runs an arbitrary package build script or compiler on the User's machine. Run consumes the validated Lock without contacting an index or modifying the Environment. A dependency without a supported wheel requires a future reviewed Runtime Profile rather than weakening reproducibility and supply-chain controls. PyPI remains a public developer and editor-integration distribution channel, not the runtime authority.
