# Build portable Python Projects from existing finite Host contracts

A Portable Factor Project constructs the existing Feature Definition graph and Feature Plan using the versioned Feature Operator Catalog, then returns the canonical Declarative Factor Definition; Python lambdas and custom operators cannot enter that Definition. The reference momentum Factor is `close → backward-simple-return(lookback) → cross-sectional-percentile → momentum-score`. A Portable Strategy Project uses only the initial versioned operation set: finite `weighted-sum`, deterministic `top-n`, `equal-weight`, and `cash-reserve`. `top-n` breaks equal scores by ascending Instrument ID. Its reference Strategy combines Forecast and Momentum scores, selects Top-N, and emits a complete Long-only Portfolio Target with a nonnegative canonical Decimal weight for every Universe member plus Cash Reserve summing exactly to one. Missing required input for any required member records `Run Pause::MissingInput` before invocation; silent row deletion is not an eligibility rule.

Factor and Strategy Definitions may reference only typed Manifest parameters with finite allowed values. A Parameter Selection Decision supplies the generated Component default, and M14 must run conformance and equivalence for every allowed combination within Host caps; Model training hyperparameters stay frozen in their Artifact. Generation passes only the canonical Definition or `adaq:linear-model@1` Artifact to fixed Rust SDK templates and compiles WASM, so Python source, Runtime, wheels, environment, and lock never enter `.adaq`. Provenance binds the Project Revision, Definition or Artifact, parameter schema, generator, SDK, ABI, toolchain, and equivalence evidence. Across Python, Arrow, Host, and WASM, identities are stable strings, event times are signed 64-bit integers, financial values, parameters, and Target weights are canonical Decimal strings, and analytical values are finite binary64 or explicitly Unavailable; NaN, infinity, object dtype, and inferred pandas identity types are rejected at the Host boundary.
