# Make Python Projects explicit, inert, and source-visible

Every Python Research Project uses one fixed root layout: exact-schema `adaq-project.toml`, editable `pyproject.toml`, ADAQ-generated `pylock.toml`, `src/project.py` plus optional declared modules, `README.md`, and `LICENSE`. Its immutable lower-kebab-case Project ID must begin with `py-factor-`, `py-model-`, or `py-strategy-` consistently with Kind; copying a bundled example requires another matching ID when one already exists and never overwrites a Working Copy. Unknown Manifest fields, enum values, or schema versions fail static Validate and block Environment preparation and execution without preventing source or historical-evidence inspection and export. A future incompatible schema may gain an explicit copy-and-upgrade action, but V1 never silently or in-place rewrites a Project.

Sync Environment is the only dependency-resolution operation: it resolves `pyproject.toml` under trusted-index, wheel-only, and hash rules and atomically replaces `pylock.toml`, making the resulting Revision untrusted. Run never resolves, installs, or rewrites dependencies. Directory and deterministic ZIP imports are inert: before copying an Untrusted Working Copy, the Host rejects absolute or parent-traversing paths, symbolic or hard links, duplicate or case-fold-colliding paths, undeclared entries, size or count limit violations, and Lock hash mismatch; it does not import a module, prepare an Environment, or execute code. Every exported Archive includes a matching licence declaration and `LICENSE`: `LicenseRef-Proprietary` is valid for local private exchange, while a zero-price Community listing requires an SPDX open-source licence permitting source redistribution.

Each Factor, Model, or Strategy Lab shows Working Copy Clean, Dirty, or Invalid; Environment Missing, Preparing, Ready, or Failed; Trust Untrusted or Trusted; and the latest Attempt. The common actions are Validate, Sync or Prepare Environment, Run, Cancel, Open Folder, and Export. Validate is static and works without Python, preparation does not grant execution trust, and Run freezes the current Revision before requesting exact-Revision trust.
