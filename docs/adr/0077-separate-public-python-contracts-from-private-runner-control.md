# Separate public Python contracts from private Runner control

ADAQ keeps one top-level `python/` workspace with two minimal wheels. `python/adaq-research-sdk/` publishes `adaq-research-sdk` and the public `adaq` namespace, including typed Factor, Model, Strategy, and `adaq.qlib` contracts. `python/adaq-python-research-runner/` remains an App-bundled private wheel whose managed CPython entry is `-I -m adaq_runner`; its protocol client and process bootstrap are not public SDK APIs. The application freezes exact hashes for both wheels and never substitutes a PyPI latest version at execution time.

The Tauri-independent Rust crate `src-tauri/crates/adaq-python-research` owns Manifest, Archive, Revision, Trust, Runner Protocol, Resource Policy, and staged Result validation contracts. The native `src-tauri/src/python_research/` control plane owns SQLite lifecycle, Working Copies, Runtime and Environment files, process supervision, and attachment to the existing persistent FIFO owned by `Features`. Factor and Model modules continue to own their evidence Stores and atomically publish only Host-validated results; Strategy joins through M13 without moving the Queue or adding a Python process pool.

Python metadata uses an independent exact `PYTHON_RESEARCH_SCHEMA_VERSION`, initially `1.0.0`. An incompatible database blocks Python Research until the User explicitly invokes device-level Reset Python Research Evidence, which removes Revision, Attempt, Trust, binding, and result metadata but preserves User Working Copies and exported Archives. Runtime, Wheelhouse, and Environment bytes remain separate evictable Cache, while Factor Candidate contract incompatibility continues to use the independently accepted Factor Research Reset.
