# Keep Client Surfaces capability-scoped and Host-authoritative

ADAQ keeps one ADAQ Host as the sole trusted authority for Authenticated User Context, authorization, evidence publication, secrets, Provider and Paper access, hard Risk and OMS, and supervised runtimes; every Client Surface is an untrusted requester. V1 embeds the Host in the Desktop application and exposes versioned, transport-independent Host Capability Contracts through a default-deny Surface Capability Profile, using bounded commands, queries, projections, domain Attempts, and non-authoritative event hints while keeping Tauri IPC private. Future Embedded Interactive, Remote Interactive, and Automation Surfaces bind one Host per session, receive no automatic Desktop parity or implicit cross-Host synchronization, and cannot turn UI state, cached projections, transport DTOs, or client-selected User IDs into authority.
