# Audit of external data libraries against ADAQ Connector contracts

Status: decision-ready research, captured 2026-08-20

## Executive decision

| Library | V1 decision | Reason in one line |
| --- | --- | --- |
| `adaq-data-stock-us` | **Exclude from V1 runtime** | It duplicates the accepted Alpaca path and exposes Yahoo-oriented, floating-point, optionally adjusted/repaired data without ADAQ acquisition provenance or capability evidence. |
| `adaq-data-stock-cn` | **Harvest selected logic only** | Its source-specific endpoint knowledge is useful, but its normalized `f64` rows, automatic provider fallback, lack of acquisition evidence, and macOS-only native dependency make the crate unsuitable as an ADAQ runtime dependency. |
| `adaq-trading-crypto` | **Keep wrapped behind the existing ADAQ adapter** | Its exact decimals and OKX realtime implementation are useful and already reused, while ADAQ must continue owning history pagination, closed-Bar rules, provenance, credentials, and the no-Live boundary. |

No new unified data-library layer is warranted. ADAQ explicitly keeps provider differences in Host-owned Connectors and rejects a speculative Unified Data API for V1 ([ADR 0030](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/docs/adr/0030-support-crypto-and-equities-through-evidence-graded-data-connectors.md#L1-L3), [V1 roadmap](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/docs/v1-roadmap.md#L21-L35)).

## ADAQ compatibility baseline

**Verified.** ADAQ's Market Data Connector is not a promise that all providers share one external API. It is Host-owned integration code that retains provider, upstream method, request, response, and connector-version provenance. Provider identity stays separate from Venue identity, and every acquisition must bind a credential-free runtime Provider Capability Snapshot ([domain contract](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/CONTEXT.md#L29-L60)).

The data contract additionally requires:

- Venue-plus-native-code Instrument identity, IANA Venue time zones, UTC millisecond instants, Venue-local calendars, and half-open historical ranges ([identity and time contract](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/CONTEXT.md#L51-L60), [Bar contract](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/CONTEXT.md#L167-L232), [ADR 0031](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/docs/adr/0031-align-market-semantics-to-venue-calendars-and-store-utc-instants.md#L1-L3)).
- Exact Decimal values; identical duplicate collapse; conflicting or malformed records retained as quarantine evidence; explicit gaps; and no canonical interpolation, clipping, normalization, adjustment, or manual repair ([ADR 0028](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/docs/adr/0028-keep-canonical-market-data-lossless.md#L1-L3)).
- Immutable Source, Canonical, quality, and Snapshot layers rather than a mutable provider cache ([ADR 0025](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/docs/adr/0025-preserve-source-canonical-and-snapshot-market-data-layers.md#L1-L3)).
- V1 data coverage limited to OKX Spot, China A-shares, and U.S. equities through Alpaca Market Data Basic. V1 execution is OKX Demo, Alpaca Paper, and ADAQ's local A-share simulator; no path accepts a Live endpoint or Real Trading credential ([roadmap](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/docs/v1-roadmap.md#L9-L19), [M9 gate](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/docs/v1-roadmap.md#L58-L62)).
- Credentials resolved only inside the Host from the operating-system secret store; they must not enter SQLite, logs, pipeline provenance, or frontend state ([Alpaca data path](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/docs/alpaca-data-path.md#L7-L16)).

The current manifest confirms that ADAQ does **not** depend on either `adaq-data-stock-*` crate. It pins `akshare = 0.1.14` and uses `adaq-trading-crypto = 1.1.0` with only `okx` and `realtime` features ([`adaq-data-core/Cargo.toml`](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/src-tauri/crates/adaq-data-core/Cargo.toml#L1-L21)).

## `adaq-data-stock-us`

### Verified facts

**API and coverage.** This is a Yahoo Finance/yfinance-compatible library, despite its U.S.-equity name. It implements price history, bulk download, corporate actions, quotes, fundamentals, options, analysis, search, screeners, calendars, news, live price streaming, and Yahoo authentication ([surface summary](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/README.md#L50-L85)). It provides no order or broker-execution surface.

**Identity and time.** Callers identify securities by a Yahoo symbol, optional `(symbol, MIC)`, or ISIN; the library maps a MIC to a Yahoo suffix and caches the result ([identifier behavior](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/README.md#L255-L287)). Historical rows use `DateTime<Utc>` and return an optional provider timezone in metadata, but they do not bind an ADAQ Venue, Trading Calendar Snapshot, Trading Date, or Session Phase ([history types](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/src/history.rs#L94-L155)).

**Numerics and transformations.** Historical OHLCV and corporate-action fields are `f64`; live prices are mostly protobuf `f32` values ([history types](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/src/history.rs#L94-L139), [live type](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/src/live.rs#L24-L95)). `auto_adjust` is enabled by default, and optional repair drops non-positive Bars and rescales pre-split prices and volume ([history options](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/src/history.rs#L50-L90), [repair implementation](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/src/history.rs#L400-L435)). The typed historical result has no raw-response bytes, response hash, request parameters, connector version, capability snapshot, retry diagnostics, or quarantine channel.

**Auth and live data.** The session handles Yahoo consent cookies and crumbs and optionally accepts raw Yahoo `T`/`Y` login cookies in `Config`; `Auth` can inspect login identity and subscription tier ([configuration](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/src/config.rs#L24-L62), [auth API](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/src/auth.rs#L7-L40)). Its WebSocket exposes a Yahoo `PricingData` tick stream with a 15-second subscription heartbeat; it is not a reproducible historical Trade, quote, or Level 2 evidence feed ([stream implementation](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/src/live.rs#L156-L244)).

**Errors, retry, and rate limits.** Retries default to zero. When configured, transport and 5xx failures use exponential backoff, a crumb-authenticated 401 resets auth, and HTTP 429 is terminal rather than honoring `Retry-After` ([defaults](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/src/config.rs#L24-L62), [retry policy](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/src/http/retry.rs#L27-L108)). The error enum is useful but has no standardized provider/method/request/retry-evidence envelope ([error taxonomy](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/src/error.rs#L8-L60)).

**Licence, platform, and maintenance.** The code is Apache-2.0 and uses Rust 2024, `primp`, bundled SQLite, rustls, Tokio, and tokio-tungstenite ([manifest](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/Cargo.toml#L1-L55), [licence](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/LICENSE#L1-L16)). The repository says no system libraries are required, but its CI verifies Ubuntu only ([requirements](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/README.md#L89-L98), [CI matrix](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/.github/workflows/ci.yml#L1-L22)). The current head is recent and green, but the project began at `0.1.0` five days before this audit and remains operationally young ([changelog](https://github.com/tonywxx/adaq-data-stock-us/blob/6262a148a1198ff030162c8619cd33d7e111343e/CHANGELOG.md#L13-L68)).

### Assessment and decision

**Inference — exclude from V1 runtime.** A direct dependency would create a second U.S.-equity authority beside the accepted Alpaca Basic Connector, while its default adjustments, optional repair, floating-point DTOs, Yahoo symbol identity, cookies, and missing acquisition envelope violate or bypass ADAQ's evidence boundary. Wrapping it correctly would require raw-byte capture before parsing, exact-decimal conversion from raw strings, `auto_adjust=false`, `repair=false`, explicit Venue/calendar mapping, Provider Capability Snapshots, gap/quarantine handling, and Host-only cookie storage. That is a new Connector, not a cheap adapter, and V1 does not need it.

If Yahoo evidence is reconsidered after V1, use it only as a separately labeled auxiliary Source for cross-checks or fundamentals. Never merge it automatically into Alpaca Canonical data, use its live tick as the sole realtime authority, or use adjusted/repaired rows as Canonical Bars. This matches ADAQ's already accepted auxiliary-yfinance boundary ([ADR 0030](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/docs/adr/0030-support-crypto-and-equities-through-evidence-graded-data-connectors.md#L1-L3)).

**Migration risks:** duplicate Source authority; silent adjusted/unadjusted mixing; irrecoverable Decimal drift after `f64` conversion; symbol collisions across Venues; cookie leakage into ordinary config/cache; Yahoo entitlement and rate-limit changes without a captured capability snapshot; and unproven Windows/macOS integration.

## `adaq-data-stock-cn`

### Verified facts

**API and coverage.** This is a broad Rust reimplementation of akshare, not a narrow A-share Connector. It claims 944 implemented public endpoints across roughly 40 domains, with 156 endpoints deliberately deferred for signing, token, JavaScript, HTML, or Excel constraints ([coverage](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/README.md#L5-L30)). It is a market-data library and exposes no broker order-execution contract.

**Provider behavior.** The high-level A-share spot call automatically tries Eastmoney, Sina, then Tencent and returns the first success. Daily history similarly falls back from Eastmoney to Tencent ([spot fallback](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/src/stock/spot/mod.rs#L9-L42), [history fallback](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/src/stock/hist/mod.rs#L8-L46)). The returned row records only the winning source; it does not retain failed attempts, raw response bytes/hashes, normalized request parameters, connector version, or a capability snapshot. Eastmoney spot does correctly paginate until the provider total is covered, which is useful source-specific logic ([Eastmoney pagination](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/src/stock/spot/eastmoney.rs#L8-L64)).

**Identity, time, and numerics.** A-share spot uses a prefix-free `code` and `f64` market values; historical rows use string dates plus `f64` OHLCV and amount fields ([spot type](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/src/stock/spot/mod.rs#L9-L31), [history type](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/src/stock/hist/mod.rs#L8-L25)). Eastmoney history accepts adjusted and unadjusted modes and converts comma-separated provider strings into `f64` ([history request/parser](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/src/stock/hist/eastmoney.rs#L8-L103)). There is no ADAQ Instrument ID, UTC/session binding, exact Decimal, invalid-row evidence, or explicit gap result.

**Auth and realtime.** The common client exposes timeout, retry, per-source rate, concurrency, and cache settings but no general credential fields ([client configuration](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/src/core/client.rs#L13-L52)). Core A-share "realtime" is an HTTP snapshot, not a WebSocket event stream. Some upstreams require static tokens, headers, browser impersonation, or future reverse engineering; those limitations are tracked as deferred coverage rather than a runtime capability snapshot.

**Errors, retry, and rate limits.** Defaults are 15-second timeout, three retries, five requests per second per source, eight concurrent requests, and no cache ([client defaults](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/src/core/client.rs#L18-L45)). The shared retry policy retries transport, `RateLimited`, and impersonation errors ([retry policy](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/src/core/resilience.rs#L64-L119)). A code-level discrepancy matters: the reqwest path sleeps for `Retry-After` on 429, then retries, but maps every other non-success status, including 5xx, to non-retryable `UpstreamChanged`; this contradicts the `ClientConfig` comment that 5xx is retried ([request loop](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/src/core/client.rs#L237-L302), [error contract](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/src/core/error.rs#L3-L25)). Retry counts/statuses are not returned with data.

**Licence, platform, and maintenance.** The code is Apache-2.0 ([manifest](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/Cargo.toml#L1-L10), [licence](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/LICENSE#L1-L16)). However, `impersonate-rs` is unconditional, `native/` is excluded from the published crate, and `build.rs` deliberately rejects every non-Apple target while requiring a vendored or system `libcurl-impersonate` dylib ([dependencies](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/Cargo.toml#L12-L45), [build gate](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/build.rs#L1-L65)). CI consequently builds/tests only on macOS; Linux runs only the Python parity check, and formatting is informational ([CI](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/.github/workflows/ci.yml#L12-L66)). The head is recent and green but the first tagged release was four days before this audit ([changelog](https://github.com/tonywxx/adaq-data-stock-cn/blob/b2dd8eaa3bc9901b5de38505999ff40cb555a2a2/CHANGELOG.md#L12-L45)).

### Assessment and decision

**Inference — harvest selected logic; do not add the crate as a V1 dependency.** Reuse source-specific request construction, complete pagination, GBK decoding, schema-drift checks, and selected parsers when they improve ADAQ's existing A-share Connector. Adapt them inside the current Host-owned raw-wire boundary so ADAQ still captures exact bytes, actual upstream/method/request/version, retry diagnostics, invalid rows, and limitations. ADAQ already does this around its pinned akshare dependency ([current A-share contract](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/docs/a-share-data-path.md#L9-L61)).

Do **not** carry over `SourceChain`'s automatic first-success behavior, `f64` DTOs, independent response cache, broad endpoint surface, or the unconditional impersonation dependency. Provider fallback must create separately identified Source evidence rather than silently changing the authority for one logical request.

**Migration risks:** Windows and Linux release failure; a much larger dependency and endpoint-drift surface; automatic upstream changes under one call; loss of raw precision/evidence before ADAQ sees a row; adjusted-price contamination; ambiguous `600000`-style identity without Venue; string-date/session errors; and false confidence from broad endpoint-count parity that does not prove ADAQ Connector semantics.

## `adaq-trading-crypto`

### Verified facts

**API and coverage.** The crate is a ccxt-compatible unified crypto and prediction-market API with 109 adapters. Its `Exchange` trait includes public market data, private account methods, and order creation/cancellation; its optional `Realtime` trait includes eight public and private channels ([README](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/README.md#L17-L32), [REST surface](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/exchange.rs#L69-L122), [order surface](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/exchange.rs#L200-L257), [Realtime surface](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/exchange.rs#L681-L718)). OKX is a curated full public/private adapter ([coverage table](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/README.md#L88-L119)).

**Auth and V1 safety.** `Config` directly carries API keys, secrets, passwords/passphrases, private keys, wallet addresses, and a caller-selected `sandbox` flag ([config](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/exchange.rs#L23-L48)). That is appropriate for a general library but cannot itself enforce ADAQ's Host secret-store boundary or prevent Live credentials/endpoints.

**Historical and realtime data.** OKX REST supports markets, ticker, order book, trades, and OHLCV, but `fetch_ohlcv` ignores `since`, makes one `/market/candles` request, supports a small interval subset, and caps the limit at 300 ([OKX implementation](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/adapters/okx.rs#L318-L405)). The realtime OKX adapter supplies ticker, sequenced order book, trades, OHLCV, balance, orders, fills, and positions over public/private sockets ([OKX realtime design](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/realtime/okx.rs#L1-L76), [methods](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/realtime/okx.rs#L344-L489)).

**Identity, time, and numerics.** Prices and quantities use `rust_decimal`, and the crate retains raw parsed JSON in `info` for many normalized structures ([numeric contract](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/README.md#L226-L242), [Ticker/OrderBook types](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/types.rs#L180-L255)). Its identity is the ccxt symbol such as `BTC/USDT`, not ADAQ's Venue plus native `BTC-USDT`. `OHLCV` has optional millisecond timestamp and exact OHLC/base volume, but no quote volume, closed/open flag, gap set, raw payload, connector version, or capability binding ([OHLCV type](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/types.rs#L564-L579)).

**Errors, retry, and rate limits.** The closed `ErrorKind` taxonomy includes authentication, permissions, rate limit, timeout, bad response, checksum, and other provider failures; retryability is centralized ([error taxonomy](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/error.rs#L10-L123)). Transport retries classified failures with linear one-second backoff, while HTTP bodies retained in error context are truncated; it does not return ADAQ acquisition diagnostics with successful data ([transport](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/transport.rs#L39-L159)). A token/rolling-window throttler exists, but `Config::new` leaves `enable_rate_limit` false unless the caller opts in ([config defaults](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/exchange.rs#L23-L58), [throttler](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/src/throttle.rs#L1-L32)).

**Licence, platform, and maintenance.** The crate is Apache-2.0; its NOTICE attributes the ccxt-compatible surface and derived parsing logic to MIT-licensed ccxt ([manifest](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/Cargo.toml#L1-L13), [NOTICE](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/NOTICE#L1-L16)). CI tests Rust 1.85 and stable with all features on Ubuntu, including nextest, clippy, formatting, and generated-adapter freshness ([CI](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/.github/workflows/ci.yml#L12-L52)). The current head is green and active, but release metadata is inconsistent: `Cargo.toml` is `1.1.0`, both `v1.0.9` and `v1.1.0` point at the same commit, and the changelog stops at `1.0.8` ([changelog head](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/CHANGELOG.md#L1-L29)).

ADAQ currently supplies a local `1.1.0` patch because the published build script emits Windows-unsafe path literals ([patch note](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/src-tauri/patches/adaq-trading-crypto/PATCH.md#L1-L11)). The audited upstream commit still inserts a display path between literal quotes rather than formatting it as an escaped Rust string, so the patch cannot yet be removed safely ([upstream build script](https://github.com/tonywxx/adaq-trading-crypto/blob/67aa9feba546c89745365a0bd27d5c39d5810b37/build.rs#L168-L181)).

### Assessment and decision

**Inference — keep it wrapped behind the existing ADAQ adapter.** Reuse only the selected OKX public market-data/realtime mechanics. Keep ADAQ's `OkxClient` and pipeline as the semantic boundary that maps native identity, enforces closed Bars and half-open ranges, paginates `/market/history-candles`, records raw response hashes and diagnostics, computes gaps, and publishes Source/Canonical/Snapshot evidence. The existing ADAQ tests demonstrate closed-Bar filtering, pagination, and explicit gap reporting that the generic `fetch_ohlcv` API does not provide ([range tests](https://github.com/tonywxx/adaq/blob/ce43b1c20bd1b9603707c1d4893adb1a67c3c343/src-tauri/crates/adaq-data-core/src/lib.rs#L2381-L2496)).

Do not expose the crate's `Exchange`/`Realtime` traits, raw `Config`, private channels, or order methods to frontend, research projects, Components, or Bot Workers. M15 should continue to put any selected private OKX mechanics behind the separate Host-owned Paper Execution Adapter, Risk, and OMS boundary; general library support for `sandbox` does not prove an endpoint is Demo-only.

Keep the local Windows patch and exact compatibility tests until a later upstream release contains the escaped-path fix. Removing the patch or broadening features should be a deliberate dependency change, not routine `cargo update` fallout.

**Migration risks:** accidental Live/order authority; raw credential propagation; incomplete historical backfill if generic `fetch_ohlcv` replaces the Host path; loss of quote volume/closed-state/gap provenance; ccxt symbol versus ADAQ Instrument identity drift; unreviewed behavior changes across a very broad adapter surface; and Windows build regression if the patch is dropped prematurely.

## Cross-library conclusion

All three codebases are Apache-2.0 at the audited commits, so their repository code licences are compatible with ADAQ's Apache-2.0 codebase. That does **not** establish rights to redistribute provider data or automate provider access; provider terms and data entitlements are separate and were not treated as settled by the code licences.

The smallest safe V1 dependency posture is the current one:

1. Keep Alpaca as the sole primary U.S.-equity Connector; do not add `adaq-data-stock-us`.
2. Keep the current ADAQ A-share Connector and pinned `akshare`; copy only reviewed source-specific logic from `adaq-data-stock-cn` when a concrete gap justifies it.
3. Keep `adaq-trading-crypto` limited to `okx` plus `realtime` and behind ADAQ-owned data and later Paper Execution adapters; retain the local Windows patch.

Any future library adoption must independently prove raw-response retention and hashes, provider capability capture, exact Decimal conversion before lossy normalization, Venue/calendar identity, explicit gaps/quarantine, bounded retry diagnostics, supported-platform CI, and Host-only credential handling. Broad endpoint parity or a green upstream CI run is useful maintenance evidence, not a substitute for those Connector gates.
