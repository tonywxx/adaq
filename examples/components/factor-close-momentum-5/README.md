# Factor Close Momentum 5

[English](README.md) | [简体中文](README.zh-CN.md)

This executable teaching Factor was generated by `adaq-component`. It emits the percentage close momentum over a fixed five-Bar lookback after five Warmup Bars.

## Develop

Read `src/lib.rs` together with `manifest.json`: `describe()` and the Manifest must agree on `close-momentum-5` and `warmupBars: 5`. Financial values remain exact decimals until the final analytical `f64` conversion.

Install Rust, `cargo-component`, and the standalone `adaq-component` CLI, then run:

```sh
adaq-component build
adaq-component verify dist/factor-close-momentum-5-0.1.0.adaq
```

`build` runs tests, compiles a release WebAssembly Component, verifies conformance, and writes the immutable package to `dist/`. Import that `.adaq` file from the ADAQ Component Library. Component code is edited in this Rust project; the Tauri app does not provide a GUI code editor.
