# Strategy Momentum Trend

[English](README.md) | [简体中文](README.zh-CN.md)

This executable teaching Strategy was generated by `adaq-component`. It combines Market close, Built-in EMA, and the external `factor-close-momentum-5` output.

## Develop

Read `src/lib.rs` together with `manifest.json` to see ordered Feature Slots, an External dependency alias, a Built-in Indicator parameter reference, `SlotIndexes`, and complete Long Only Target Exposure decisions.

Install Rust, `cargo-component`, and the standalone `adaq-component` CLI, then run:

```sh
adaq-component build
adaq-component verify dist/strategy-momentum-trend-0.1.0.adaq
```

`build` runs tests, compiles a release WebAssembly Component, verifies conformance, and writes the immutable package to `dist/`. Import that `.adaq` file from the ADAQ Component Library. Component code is edited in this Rust project; the Tauri app does not provide a GUI code editor.

Import the Factor Package before this Strategy, then bind the `momentum` dependency in Backtest. Continue with the complete [English tutorial](../README.md) or [简体中文教程](../README.zh-CN.md).
