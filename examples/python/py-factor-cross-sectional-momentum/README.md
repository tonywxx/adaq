# Python Cross-sectional Momentum Factor

This Apache-2.0, source-visible Project is a **Synthetic Demonstration** for
the offline ADAQ M12 tutorial. It consumes Host-supplied close evidence and
constructs `close → backward simple return → cross-sectional percentile →
momentum score` with the Host-owned `lookback={5,20,60}` Grid and default 20.

It does not contain market data, credentials, a Runtime, an Environment, or
results. ADAQ validates this source without importing it and only executes an
immutable trusted Revision.
