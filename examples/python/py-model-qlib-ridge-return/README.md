# Host-fed Qlib Ridge Return Model

This Apache-2.0, source-visible Project is a **Synthetic Demonstration** for
the offline ADAQ M12 tutorial. The registered Host-fed Qlib Ridge Adapter owns
the five-Bar continuous future-close-return target, Train-only transformation,
`alpha={0.1,1,10}` Grid, pickle-free Linear Model Artifact, and Host-computed
Forecast evidence.

The Project contains no provider, Qlib data directory, data, credentials,
Runtime, Environment, or results. Its Python entry point declares the model
contract; the Adapter, not arbitrary Project code, owns the qualified fit.
