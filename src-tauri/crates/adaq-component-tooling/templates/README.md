# {{display_name}}

This project is an ADAQ Component generated by `adaq-component`.

## Develop

Edit `src/lib.rs` to implement the component and `manifest.json` to declare its stable metadata. Financial values are decimal strings; keep them exact until an analytical `f64` output is required.

Install Rust, `cargo-component`, and the standalone `adaq-component` CLI, then run:

```sh
adaq-component build
adaq-component verify dist/{{name}}-0.1.0.adaq
```

`build` runs tests, compiles a release WebAssembly Component, verifies conformance, and writes the immutable package to `dist/`. Import that `.adaq` file from the ADAQ Component Library. Component code is edited in this Rust project; the Tauri app does not provide a GUI code editor.
